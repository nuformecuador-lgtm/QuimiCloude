# Catálogo de componentes

Índice de las piezas de UI que ya existen: primitivos de `components/ui`, compuestos de
`components/shared` y apoyos de `lib/shared/ui` y `hooks`. Antes de crear un componente se busca
aquí y se aplica la regla de decisión: **reutiliza, extiende, compón y, solo si nada de eso basta,
crea** (`docs/perfil-agentes.md > Todos los agentes > Regla de decisión para componentes`). Quien
crea, sube, extiende o borra una pieza actualiza su fila en el mismo commit: una pieza nueva es
**una fila** insertada en su sitio (orden por `Archivo`), nunca una sección nueva. `Alcance` dice
siempre qué cubre y qué no; `Base de` solo cita piezas de este catálogo; `Diseño` lleva el tablero
aprobado en `docs/diseno/canvas/`, `previo al rediseño` para lo que ya estaba o `sin UI` para lo
que no pinta. La guardia `tests/guards/guard-catalogo-de-componentes.test.ts` cruza estas tablas
con el código en las dos direcciones.
