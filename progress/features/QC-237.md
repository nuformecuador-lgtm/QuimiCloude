- El contexto del cifrado es el `SecretContext` de QC-234 (`companyId`, `recordId`, `field`,

  decide si se queda (solo para el inventario de QC-250) o se quita.
- Las variables `INTEGRATIONS_ENCRYPTION_KEYS`/`_ACTIVE` aún no existen en Vercel.
